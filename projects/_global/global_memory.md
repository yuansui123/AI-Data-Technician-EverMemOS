

## Procedure
PROCEDURE — Always save original file IDs when remembering signal examples, artifacts, or any labeled signal. For each signal, always record:
1. Signal number / position in the batch (e.g. #8)
2. Index from metadata (e.g. 40391)
3. Full filename (e.g. x040391.mat)
4. Channel name (e.g. RPD_2)
5. Anatomy / brain region
6. Patient ID
7. SOZ label
8. Any artifact or pattern label

This applies to ALL future memory entries involving signals — artifacts, SOZ examples, HFO examples, etc. Never save a signal memory without its full file ID chain (index → filename).
